Лабораторная работа: Отработка HTTP-запросов в PHP с использованием cURL
👨‍🎓 Цель работы
Освоить основные принципы работы с библиотекой cURL в PHP для выполнения HTTP-запросов различных типов, обработки ответов сервера, передачи заголовков, обработки ошибок и работы с API.

🧠 Теоретические сведения
cURL (Client URL) — это библиотека и инструмент командной строки для передачи данных по различным протоколам. В PHP встроено расширение libcurl, позволяющее:

выполнять HTTP-запросы (GET, POST, PUT, DELETE),

загружать и отправлять файлы,

передавать заголовки,

использовать аутентификацию,

взаимодействовать с API.
